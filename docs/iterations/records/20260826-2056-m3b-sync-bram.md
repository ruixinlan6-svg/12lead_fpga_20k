## Problem and evidence

- Observed problem: the M3 model-level graph and UART/SDRAM behavior simulation were exact, but Gowin synthesis inferred the asynchronous CNN `input_mem` as 131,072 DFF and stopped above the 15,915-DFF device limit.
- Evidence from baseline: the M3 build log reported `ERROR (IF0008)` at `input_mem`; no full-model PnR or board logits existed.
- Primary repair: replace all large CNN stores with synchronous-read `ecg_sync_dp_ram` memories, share the mutually exclusive first/second residual activation buffer, and link the RAM-rich core as a separately synthesized SDPB netlist.

## Optimization

- Method: refactor the CNN memory path to synchronous BRAM-compatible read ports, keep the existing tensor order and quantization, receive weights in 100-byte UART chunks, write/read/compare each chunk through SDRAM, and link the independently mapped core netlist into the top-level SDRAM/UART design.
- Why this method: Gowin BSRAM inference requires synchronous memory coding; reducing model dimensions or hardcoding a Golden output would not satisfy the full-network deployment requirement.
- Alternatives considered and why not selected: keeping asynchronous arrays is already rejected by synthesis; configuration/Flash weight storage avoids the SDRAM requirement; GoAI/NPU storage compatibility with QN88 SDRAM remains unproven.
- Expected mechanism: every memory read is registered and each MAC/pool/GAP request has an explicit request/execute pair. The core-only build maps 36 SDPBs; the linked top-level build keeps those blocks while avoiding top-level optimizer duplication.

## Frozen acceptance criteria

- Success threshold: software integer, RTL layer buffers, and wrapper SDRAM readback remain exact; Gowin synthesis and PnR complete with no errors/timing violations; resource report identifies BSRAM/DSP use; SRAM-only QN88 image downloads and COM10 returns `ECG P1 S1 D1` with logits `{32,-22,-21,-19,-21}`.
- Failure/rollback threshold: any first mismatch, synthesis/PnR error, timing/resource overflow, SDRAM status failure, or missing/incorrect UART frame rejects this run; retain M3 behavioral evidence and do not write Flash.
- Fixed test set and conditions: corrected M2 first validation Golden, 12×1000 signed INT8 input, 10,293-byte parameter stream, 115200 8-N-1, COM10, volatile SDRAM only.
