## Problem and evidence

- Observed problem: LUDB does not annotate the first and last cardiac cycles, so treating every detector output over the full 10-second signal as a scored false positive penalizes valid boundary beats. The old milestone also incorrectly required independent float and deployment-integer timestamps to be identical.
- Evidence from the baseline: the conservative rounded support analysis retained fixed QTP/QFN/QFP `1824/8/9`, Gross Se/+P `99.563%/99.509%`, while the full 10-second diagnostic was `1824/8/333`; detector outputs were unchanged.
- Primary metric or failure point: formalize a non-retrospective scoring scope and implementation responsibility without hiding full-record behavior.

## Optimization

- Method: with explicit user approval, freeze LUDB medical-gate scoring to the inclusive time interval `[first reference - 150 ms, last reference + 150 ms]`; keep full 10-second metrics mandatory and backward-compatible; use the causal pure-integer path for the M1 gate; retain the independent float path as a diagnostic; move bit-exact responsibility to integer Golden → RTL → FPGA.
- Why this method: it aligns the scored interval with the database's actual annotation support while preserving all detector outputs and exposing both scopes.
- Alternatives considered and why not selected: suppressing startup/end detections would alter valid streaming behavior; scoring the unannotated boundary as negative would preserve a known label error; requiring float/integer equality would erase the independent-reference role.
- Expected mechanism: only evaluation accounting and responsibility text change; detector parameters, detector outputs, LUDB annotations, and thresholds remain frozen.

## Frozen acceptance criteria

- Success threshold: LUDB 200/200 records, zero evaluation errors; causal pure-integer annotation-support Gross and Average `QRS Se >= 99.5%` and `QRS +P >= 99.5%`; gross `QFN <= 9` and `QFP <= 9`; maximum annotation mapping error `<= 2.0 ms` with numerical tolerance only.
- Failure/rollback threshold: any detector-output change; missing full-record metrics; locked-database access; fewer than 200 records; any gate below threshold; test regression; or contract/report ambiguity about which scope is accepted.
- Fixed test set, thresholds and measurement conditions: LUDB 1.0.1, 250 Hz target, 150 ms match tolerance, no learning period, exact inclusive time support `[first_reference - 0.150 s, last_reference + 0.150 s]`. Full 10-second metrics remain required diagnostics and their fixed baseline must reproduce QTP/QFN/QFP `1824/8/333`. Independent float metrics and float/integer differences remain mandatory diagnostics but are not an equality gate. Pure-integer causality, prefix invariance, arbitrary chunk equivalence, and no event loss remain mandatory. Acceptance thresholds may not be changed after evaluation.
