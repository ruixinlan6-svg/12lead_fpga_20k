## Problem and evidence

- Observed problem: the accepted software INT8 model and short QN88 SDRAM smoke existed, but no model-sized path loaded the full input/weights through SDRAM and returned all five ECG logits.
- Frozen graph: `12x1000 -> 16x1000 -> 16x500 -> 32x500 -> 32x250 -> 32x250 -> 32 -> 5`; parameter payload is 10,293 signed-INT8 bytes, packed little-endian into 2,574 words and 103 bursts of 25 valid words (last burst padded).
- Primary gate: exact software integer reference, exact layer-by-layer RTL, exact SDRAM payload readback, then successful QN88 synthesis/PnR and SRAM-only board UART logits.

## Optimization

- Method: add a fixed-shape TinyECGCNN integer RTL core, a UART byte loader, a byte-write/word-read BSRAM weight store, a 25-word SDRAM burst FIFO, readback comparison, and a UART logits frame. The wrapper protocol is `ECG0` + 12,000 input bytes + 10,293 parameter bytes.
- Why: this isolates the missing model/memory/protocol boundary while preserving the accepted PTQ contract and signed INT8 byte order. SDRAM readback is verified before weights are copied into the CNN core.
- Alternatives rejected: configuration/Flash-resident weights would not test SDRAM loading; GoAI compatibility with QN88 plus external SDRAM is not established; a generic NPU would change this milestone.

## Frozen acceptance criteria

- Success: all software/RTL buffers and five logits exact; all SDRAM payload words compare; Gowin synthesis/PnR succeeds with usable BSRAM/DSP/timing; QN88 SRAM-only download returns the same five logits at 115200 8-N-1; no Flash write.
- Failure: any parity mismatch, unverified readback, resource/timing error, or absent board UART frame rejects the model-level hardware claim and retains the prior smoke baseline.
- Golden condition: corrected M2 first validation vector, signed INT8, 12 leads × 1000 samples, five output logits.

- Why the failure is structural: the core uses combinational/asynchronous memory reads to keep the reference testbench simple. Gowin block-RAM inference requires a compatible synchronous-read style; an attribute alone did not convert this implementation. ## Decision

- Decision: `reject model-level hardware claim; continue with M3b`.
- Reason: model arithmetic and behavioral end-to-end protocol pass, but Gowin synthesis fails before PnR on the asynchronous CNN memories. This is a hardware implementation blocker, not an accuracy or SDRAM protocol failure.
- What changed: added the complete software/RTL/wrapper path and its self-checking simulations; no board image or Flash contents were changed.
- Next delivery node: redesign the CNN buffers/weight memories around synchronous BRAM reads or explicit Gowin `SP/SDPB/DPB` primitives, pipeline MAC address/valid signals, rerun synthesis/PnR, then perform SRAM-only QN88 download and COM10 UART HIL with the same Golden frame.
